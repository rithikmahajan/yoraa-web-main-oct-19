# Yoraa Web Application

A modern e-commerce web application built with React + Vite.

## Features

- Modern React application with Vite for fast development
- E-commerce functionality with cart, wishlist, and product management
- Firebase integration for authentication and data
- Responsive design with Tailwind CSS
- State management with Redux Toolkit

## Tech Stack

- **Frontend**: React, Vite, Tailwind CSS
- **State Management**: Redux Toolkit
- **Authentication**: Firebase
- **Build Tool**: Vite
- **Styling**: Tailwind CSS

## Getting Started

This template provides a minimal setup to get React working in Vite with HMR and some ESLint rules.

Currently, two official plugins are available:

- [@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react/README.md) uses [Babel](https://babeljs.io/) for Fast Refresh
- [@vitejs/plugin-react-swc](https://github.com/vitejs/vite-plugin-react-swc) uses [SWC](https://swc.rs/) for Fast Refresh
